# AutoQuote releases

Signed Android APKs of **AutoQuote**, an offline quotation app for Mahindra showrooms by CA Akshay Daiya
([catool.co.in](https://catool.co.in)). This repository holds only the release files; the source code is private.

The app checks the latest release here (Settings > App Updates), downloads the APK, verifies it against
`SHA256SUMS.txt` and the app's signing key, and then asks you to confirm the install.
